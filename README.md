# WebApp Lecture — Exam Preparation Repository

This repository contains all materials required to prepare for the **Web Applications** exam.
It is focused on **practical programming tasks** using **JSF** and **Spring MVC**, following the exact structure and patterns used in the examination.

## Exam
- [EXAM INDEX](EXAM_INDEX.md)
- [Exam Quickstart](docs/00-EXAM-QUICKSTART.md)


## Purpose
The goal of this repository is to provide:
- A clear structure aligned with the exam format
- Checklists for each task type
- Copy-ready code snippets
- Solved exercises and reference projects (Shop24)

## Exam Scope (Summary)
The exam consists of:
- 4 programming tasks
- 2 prepared Maven projects
- JSF and Spring MVC tasks
- Typical workflow:
  **Form → Read data → Validation → List → Details**

> Correct, simple and compiling code is more important than complex solutions.

Compile errors immediately stop evaluation.
